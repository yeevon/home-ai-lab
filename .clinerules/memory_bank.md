# Memory Bank
At the start of every task, read memory-bank/activeContext.md and memory-bank/decisions.md if they exist.

At the end of every task, append to memory-bank/decisions.md:

## [date/time] - [one-line task summary]
**Decision:** what was done
**Reasoning:** why this approach over alternatives
**Files changed:** list
**Outcome:** tested? passed? known issues?

Keep activeContext.md updated with current project state so a new session can resume without you re-explaining context.
